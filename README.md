# Hi, I'm Daniela 👋

**Product Designer + UX/UI Designer based in Mexico City.**

**design, technology and AI.**

My background in graphic design and web implementation allows me to move

actually build.

Currently focused on **Product Design, UX/UI and AI-powered digital products**.

## What I do

- **Product & UX/UI Design:** user flows, wireframes, prototypes and interface design
- **UX Research:** competitive analysis, user interviews, journey mapping and usability
- **Design Systems:** components, variants, responsive patterns and visual consistency
- **Web Design:** responsive websites, landing pages and ecommerce experiences
- **Front-end:** HTML, CSS, JavaScript, Astro and Tailwind CSS
- **AI + Design:** exploring AI-assisted workflows, automation and conversational products
